# PharmaLink Ethiopia — User Stories

**Document Type:** User Stories (Agile Backlog)
**Product:** PharmaLink Ethiopia — Digital Healthcare Marketplace
**Version:** 1.0
**Prepared by:** Senior Business Analyst
**Status:** Draft for Review

## 1. Purpose
This document captures user stories from the perspective of each stakeholder, using the format *"As a [role], I want [goal], so that [benefit]."* Stories are grouped by epic, uniquely identified (US), and prioritized with MoSCoW. Detailed acceptance criteria are maintained in the Acceptance Criteria document (referenced by ID).

## 13. Prioritization Summary
Must-have stories establish the core medicine marketplace loop (discover, prescribe, pay, deliver) plus provider onboarding, payments, and compliance. Should-have stories add healthcare services (appointments, diagnostics). Could-have stories cover enhancements such as result delivery and waiting lists. See the Feature Prioritization and Product Roadmap documents for sequencing.
